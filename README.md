- 일정: 2026년 11월 10일(화)–12월 15일(화), 매주 화요일 6회 (11.10 / 11.17 / 11.24 / 12.1 / 12.8 / 12.15)
- 시간: 오전반 08:00–12:00, 오후반 13:00–17:00 (반별 회차당 4시간, 같은 내용)
- 장소: 경기 안산시 단원구 동산로27번길 42-25, 신흥안산공장 생산동 2층 회의실 (㈜신흥 찾아가는 교육)
- 실습 도구: Claude Cowork — Claude 유료 계정 2개월 지원
- 필수 지참: 실물 또는 모바일 신분증(캡처본·사진 불가), Windows 10 이상 개인 노트북
